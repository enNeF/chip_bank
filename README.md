# Hold'em Chip Bank

A single-page chip tracker for home Texas Hold'em games. It handles the betting so you can play with real cards and no physical chips.

- Blinds, dealer button, betting rounds and side pots handled automatically
- Showdown hand checker that works out the winner from the cards
- Results tab with buy-ins, rebuys and net per player
- Optional blind timer that raises blinds on a schedule
- Learn and hand-ranking tabs for new players
- Undo for misclicks; state is saved in the browser's localStorage

## Run it

Open `index.html` in any browser. No build step or server needed.
